# Презентация: Airfoil Self-Noise Prediction

## 1. Problem

Задача: предсказать уровень шума аэродинамического профиля по параметрам потока и геометрии.

Практический смысл: быстро оценивать шум до дополнительных испытаний и сравнивать варианты профиля.

---

## 2. Data

Источник: UCI Airfoil Self-Noise.

Датасет:

- 1503 строки;
- 5 входных признаков;
- 1 целевая переменная `scaled-sound-pressure`;
- пропусков и дублей не обнаружено.

---

## 3. EDA

Проверено:

- hist для всех входных признаков;
- boxplot для выбросов;
- target distribution;
- correlation heatmap.

Вывод: признаки имеют разные масштабы, часть значений дискретна, линейные корреляции не описывают задачу полностью.

---

## 4. Models

Baseline и модели:

- `DummyRegressor`;
- `LinearRegression`;
- `DecisionTreeRegressor`;
- `KNeighborsRegressor`;
- `RandomForestRegressor`.

Подбор параметров выполнен через `GridSearchCV`.

---

## 5. Metrics

Финальная модель: `RandomForestRegressor`.

Лучшие параметры:

- `max_depth=None`;
- `min_samples_leaf=1`;
- `n_estimators=200`.

Метрики на тестовой выборке:

| Метрика | Значение |
| --- | ---: |
| MAE | 1.299809 |
| RMSE | 1.813235 |
| R2 | 0.934373 |

---

## 6. Interpretation

Добавлено:

- `feature_importances_`;
- permutation importance;
- таблица топ-5 ошибок.

Вывод: признаки с высокой важностью нужно контролировать при сборе новых данных и анализе ошибок.

---

## 7. Inference

Сервис:

- Flask;
- endpoint `POST /api/inference`;
- HTML-форма для ручной проверки;
- модель загружается из `data/random_forest_model.pkl`.

Пример результата API:

```json
{
  "prediction": 129.27325000000033
}
```

---

## 8. Выводы

1. Модель подходит для предварительной оценки шума профиля.
2. Random Forest показывает качество выше baseline-моделей.
3. Прогнозы нельзя использовать вне диапазонов исходного датасета без дополнительной проверки.
4. Для практического внедрения полезно расширить датасет новыми экспериментами.
