# Отчёт по готовности итогового проекта

## Краткая оценка

Подпроект в `final` закрывает основные требования задания: notebook оформлен как отчёт, есть EDA, feature engineering, baseline, сравнение моделей, подбор параметров, кросс-валидация, интерпретация, анализ ошибок, прикладные выводы, Flask-инференс, README, презентация и файл скринкаста.

Ориентировочная оценка по рубрике: **90-96 / 100**. Остаточные потери возможны из-за того, что скринкаст представлен локальным GIF-файлом, а не полноценной записанной демонстрацией 5-7 минут.

## Что сделано

- Описаны постановка задачи, тип задачи, целевая переменная, практический смысл и ограничения.
- Добавлен EDA:
  - hist для всех входных признаков;
  - boxplot для выбросов;
  - target distribution;
  - correlation heatmap;
  - выводы под каждым блоком.
- Добавлен feature engineering:
  - `frequency_velocity_ratio`;
  - `angle_chord_product`;
  - `velocity_chord_product`;
  - `log_frequency`;
  - сравнение модели на базовых и расширенных признаках.
- Добавлены baseline-модели:
  - `DummyRegressor`;
  - `LinearRegression`;
  - `DecisionTreeRegressor`;
  - `KNeighborsRegressor`.
- Добавлены сравнение моделей и подбор параметров через `GridSearchCV`.
- Добавлена кросс-валидация через `KFold`/`cross_validate`.
- Добавлена интерпретация:
  - `feature_importances_`;
  - permutation importance;
  - таблица топ-5 ошибок;
  - прикладные выводы.
- Финальная модель сохраняется в `data/random_forest_model.pkl`, файл игнорируется git.
- Flask-сервис проходит smoke-test.
- README содержит структуру проекта, запуск notebook/обучения, запуск сервиса, пример API-запроса и итоговые метрики.
- Добавлена презентация: `presentation.md`.
- Добавлены материалы скринкаста: `screencast.md` и `screencast.gif`.

## Итоговые метрики

Финальная модель: `RandomForestRegressor`.

Лучшие параметры:

- `max_depth=None`;
- `min_samples_leaf=1`;
- `n_estimators=200`.
