# Отчёт по соответствию итогового проекта заданию

## Краткая оценка

Текущий подпроект частично соответствует заданию: есть датасет, оформленный ноутбук с первичным анализом данных, обучением `RandomForestRegressor`, сохранённая модель, `requirements.txt` и простой Flask-сервис для инференса. Основной риск теперь не в форме отчёта, а в недостающих ML-блоках рубрики: baseline, сравнение моделей, подбор гиперпараметров, интерпретация и прикладные выводы.

Ориентировочная оценка по рубрике: **50-60 / 100**. Это уже ближе к минимальному проходному уровню, но для уверенной оценки всё ещё нужно закрыть baseline, сравнение моделей, подбор параметров, интерпретацию и материалы защиты.

## Что уже сделано

- Выбрана задача варианта 13: прогноз уровня шума аэродинамического профиля.
- Используется датасет UCI Airfoil Self-Noise: `1503` строки, `6` столбцов, пропусков в CSV не обнаружено.

- Постановка задачи, тип задачи, целевая переменная, практический смысл и ограничение применения описаны в ноутбуке.
- В `task.ipynb` загружаются данные, выделяются признаки и целевая переменная.
- Добавлена первичная проверка данных: размер, типы, пропуски, дубли, `describe()`, распределения признаков и корреляционная матрица.
- После ключевых блоков добавлены короткие выводы.
- Выполнено разбиение `train_test_split` с `random_state=42`.
- Обучена модель `RandomForestRegressor(n_estimators=1000, random_state=42)`.

- Модель сохранена в `data/random_forest_model.pkl`.
- Есть Flask-приложение с эндпоинтом `/api/inference` и HTML-формой.
- В локальном `.venv` установлены нужные зависимости: Flask `3.1.3`, joblib `1.4.2`, scikit-learn `1.6.0`, pandas `2.3.3`.
- Smoke-test Flask-приложения через `.venv` проходит: `GET /` возвращает `200`, `POST /api/inference` возвращает прогноз.

## Основные проблемы

1. **Нет baseline-модели**

   Сразу обучается Random Forest. По критериям нужна простая baseline-модель: например, `DummyRegressor`, `LinearRegression`, `DecisionTreeRegressor` или KNN, с анализом качества.

2. **Нет сравнения моделей и подбора гиперпараметров**

   Не реализованы `GridSearchCV`, `RandomizedSearchCV` или кросс-валидация. Нет таблицы сравнения baseline и нескольких моделей.

3. **Валидация описана слабо**

   Есть только одно разбиение train/test. Нет обоснования схемы, нет проверки стабильности результата на кросс-валидации, нет обсуждения риска переобучения.

4. **Нет интерпретации**

   Не показаны важности признаков (`feature_importances_`, permutation importance или SHAP), нет анализа ошибок и примеров удачных/неудачных предсказаний.

5. **Нет прикладных выводов и рисков**

   Не сформулировано, как заказчику использовать модель, при каких условиях ей нельзя доверять, какие есть ограничения данных и внедрения.

6. **README неполный**

   В `app/readme.md` есть описание и установка зависимостей, но нет команды запуска, примера API-запроса, описания входных параметров, ожидаемого ответа и структуры проекта.

7. **Зависимости не закреплены**

    В `requirements.txt` указаны пакеты без версий. Воспроизводимость лучше обеспечить фиксированными версиями.

8. **Нет презентации и скринкаста**

    В папке `final` не обнаружены презентация и скринкаст 5-7 минут, которые прямо требуются заданием.
